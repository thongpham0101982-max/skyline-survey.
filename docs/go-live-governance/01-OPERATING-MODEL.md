# 01. SSM OPERATING MODEL & VẬN HÀNH LIÊN TỤC

---

## 1. SƠ ĐỒ CHU TRÌNH VẬN HÀNH CHUẨN (OPERATIONAL LIFECYCLE)

```text
+-----------------------------------------------------------------------------------+
| 1. MONITOR (Giám sát)                                                            |
|    - Theo dõi Telemetry, Uptime, Error Rate, Task Completion, User Feedback       |
+-----------------------------------------------------------------------------------+
                                         │
                                         ▼
+-----------------------------------------------------------------------------------+
| 2. RECEIVE CHANGE (Tiếp nhận yêu cầu)                                             |
|    - Thu nhận qua Change Request Template chuẩn (không nhận yêu cầu miệng/chat)    |
+-----------------------------------------------------------------------------------+
                                         │
                                         ▼
+-----------------------------------------------------------------------------------+
| 3. ASSESS & PRIORITIZE (Đánh giá tác động & Ưu tiên)                               |
|    - Đánh giá DB, API, RBAC, UI, Bảo mật, Nguy cơ; Xếp hạng P0 -> P3               |
+-----------------------------------------------------------------------------------+
                                         │
                                         ▼
+-----------------------------------------------------------------------------------+
| 4. APPROVE (Phê duyệt thay đổi)                                                  |
|    - Hội đồng phê duyệt (Business Owner, Tech Lead, Data Owner, KT&ĐBCL) ký duyệt |
+-----------------------------------------------------------------------------------+
                                         │
                                         ▼
+-----------------------------------------------------------------------------------+
| 5. IMPLEMENT & TEST (Phát triển & Kiểm thử)                                       |
|    - Tái sử dụng Design System Primitives; Unit Test + Integration Test + QA Staging|
+-----------------------------------------------------------------------------------+
                                         │
                                         ▼
+-----------------------------------------------------------------------------------+
| 6. RELEASE (Phát hành có kiểm soát)                                              |
|    - Atomic Zero-Downtime Deployment; Release Checklist; Sẵn sàng Rollback        |
+-----------------------------------------------------------------------------------+
                                         │
                                         ▼
+-----------------------------------------------------------------------------------+
| 7. MEASURE, REVIEW & IMPROVE (Đo lường, Đánh giá & Cải tiến)                      |
|    - Đánh giá Adoption, Task Success Rate, Cập nhật Baseline Changelog            |
+-----------------------------------------------------------------------------------+
```
