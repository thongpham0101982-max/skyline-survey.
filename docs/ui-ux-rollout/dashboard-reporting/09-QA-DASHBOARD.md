# 09. THIẾT KẾ DASHBOARD BAN KT&ĐBCL TOÀN HỆ THỐNG
## KIỂM ĐỊNH CHẤT LƯỢNG HỌC THUẬT VÀ GIÁM SÁT DỮ LIỆU HỆ THỐNG

---

### 1. Trọng tâm Kiểm soát Toàn Hệ Thống
- **Đối chuẩn liên cơ sở (Cross-Campus Benchmarking)**: So sánh điểm trung bình và độ lệch chuẩn của các cơ sở so với Điểm trung bình hệ thống (System Mean).
- **Trung tâm Giám sát Chất lượng Dữ liệu (Data Quality Center)**:
  - Phát hiện các trường hợp sổ điểm nộp trễ hạn.
  - Học sinh vắng kiểm tra chưa cập nhật nguyên nhân.
  - Câu hỏi thư viện thiếu mạch kiến thức hoặc mức độ tư duy.
- **Tiến độ Dự giờ và Khảo thí toàn hệ thống**: Thống kê mức độ hoàn thành chỉ tiêu chuyên môn của từng cơ sở.
