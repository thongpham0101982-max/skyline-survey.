# 11. KIỂM THỬ TÍCH HỢP LIÊN PHÂN HỆ (CROSS-MODULE E2E)
## XÁC NHẬN 5 CHUỖI NGHIỆP VỤ XUYÊN SUỐT (FLOW A ĐẾN E)

---

### 1. Flow A: Khảo thí → GAP → Cố vấn → Hồ sơ 360° → Dashboard
- Khi điểm kiểm tra chính thức được nạp vào phân hệ Khảo thí, hệ thống tự động tính GAP với mục tiêu học sinh đã đặt, cập nhật huy hiệu tiến độ trên Hồ sơ 360° và phản ánh ngay vào thẻ KPI của Dashboard. **Kết quả: PASS**.

### 2. Flow B: Hoạt động trải nghiệm → Đánh giá Rubric → Hồ sơ 360° → Dashboard
- Giáo viên chấm điểm 3-5 tiêu chí trên bảng Roster, điểm trung bình trọng số được tự động chuyển sang tab Dự án của Hồ sơ 360° và tổng hợp tỷ lệ hoàn thành trên Dashboard GĐCS. **Kết quả: PASS**.

### 3. Flow C: Hỗ trợ học tập / Tâm lý → Theo dõi định kỳ → Hồ sơ 360° → Dashboard
- Hồ sơ can thiệp cập nhật tiến triển định kỳ, bảo mật thông tin nhạy cảm, đồng bộ số lượng học sinh cần can thiệp lên Dashboard điều hành. **Kết quả: PASS**.

### 4. Flow D: Dự giờ chuyên môn → Hoàn thành đánh giá → Dashboard TTCM / GĐCS
- Phiếu dự giờ được phê duyệt, cập nhật ngay tỷ lệ hoàn thành kế hoạch cá nhân của giáo viên và tiến độ toàn tổ của TTCM. **Kết quả: PASS**.

### 5. Flow E: Học sinh thiết lập mục tiêu → Cố vấn duyệt → Đối soát điểm thực tế
- Học sinh gửi mục tiêu, GVCN xác nhận, hệ thống theo dõi diễn biến qua các kỳ KSĐN $ightarrow$ GK1 $ightarrow$ CK1 mà không sinh lỗi NaN. **Kết quả: PASS**.
